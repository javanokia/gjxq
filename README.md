# 3D 国际象棋 (3D Royal Chess) - 纯静态 P2P 联机版

基于 **Three.js**、**chess.js**、**WebRTC (PeerJS)** 与 **TypeScript** 构建的高品质 3D 国际象棋网页游戏。

> **纯静态免服务器支持**：支持 100% 部署在 GitHub Pages、Vercel、Cloudflare Pages 等静态托管平台，无需购买或维护任何后端服务器，即可通过 WebRTC P2P 浏览器端对端加密直连进行跨网络全球好友对战！

---

## ✨ 核心特性

### 1. 🌐 WebRTC P2P 端到端直连对战 (无需后端服务器)
- **纯数字 6 位房间号**：一键生成 6 位纯数字房间码（如 `682910`），输入即可极速直连。
- **一键分享邀请链接**：点击“复制链接”即可生成带 `?room=682910` 的邀请链接，对方打开页面自动切换联机并加入。
- **WebRTC DataChannel 极速低延迟**：两国/两地玩家浏览器建立 P2P 加密隧道直接交换着法与表情，无需经过中心服务器转发。
- **内置全球 STUN 穿透配置**：预置 Google、Cloudflare 等多节点免费 STUN 穿透服务器，无惧家用 NAT 与跨运营商。
- **房主执子自选**：房主可指定执白、执黑或随机。
- **局内实时交互**：
  - 快捷短语与互动提醒（“妙手！精彩！”、“承让承让！”、“下得漂亮！”等）。
  - 提议和棋 (Offer Draw) 与确认流程。
  - 认输 (Resign) 结算。
  - 再战一局 (Rematch) 双方同意后自动交换先手黑白棋重开。

### 2. 🎨 极致 3D 视觉与四大多重场景氛围 (Three.js)
- **4 大精美场景氛围一键切换**：
  1. **皇家殿堂 (Royal Grand Hall)**：金碧辉煌古典大厅、拱窗日光与卡拉拉大理石台面。
  2. **摩天阁楼 (Penthouse Skyline)**：现代高空天际线全景、极简工业微水泥桌面与午夜蓝台面。
  3. **静谧书斋 (Cozy Study)**：典雅红木书架、复古绿色银行家台灯与温暖壁炉漫射光。
  4. **国际赛事 (Tournament Arena)**：现代化世锦赛比赛舞台、无影专业柔光与专业比赛绿白格。
- **抗眩光缎面漫反射棋盘**：彻底消除刺眼光斑，在各种光线条件下黑白棋子轮廓清晰锐利。
- **平面超清坐标刻字**：A-H 与 1-8 刻印完全贴合木质边框上表面，任何观察视角下均清晰无遮挡。
- **Staunton 经典斯当东棋子建模**：王（十字架）、后（珍珠冠冕）、象（尖顶切口）、马（精细鬃毛与马头轮廓）、车（城堞雉堞）、兵（标准球顶），底座带黄铜配重环与丝绒防滑垫。
- **零 Emoji 现代化矢量 UI**：全界面使用自研精细 SVG 矢量图标。
- **物理起落与吃子动画**：抛物线起伏走子，吃子侧倾滑出棋盘，获胜全屏五彩礼花爆炸 (`canvas-confetti`)。
- **5 种摄像机视角预设**：白方视角、黑方视角、平面俯视、3D等角剧场视角、侧翼观战，并支持自由旋转与平移缩放。

### 3. ♟️ 完整国际象棋规则 (chess.js)
- 完整支持王车易位（短易位/长易位）、吃过路兵 (En Passant)、兵升变 (Pawn Promotion: 后/车/象/马)。
- 绝杀 (Checkmate)、逼和 (Stalemate)、三次重复局面、50 步规则、子力不足等官方判定。
- 标准代数记谱法（SAN）实时着法表滚动，实时子力斩获统计与净胜子分展示。

### 4. 🤖 本地 AI 智能对弈引擎 (Minimax + Alpha-Beta)
- 100% 浏览器本地运算，无需连网。
- 采用 1D 打平紧凑 `Int16Array` 位置价值表 (PST) 与 MVV-LVA 走法排序。
- 提供简单、中等、大师 3 种难度等级。

### 5. 🔊 纯 Web Audio 声音合成
- 无需下载任何外部 mp3 音频，由浏览器振荡器合成木质落子声、吃子击打声、易位滑行动作、将军警报与胜利和弦。

## 🚀 静态网站部署指南 (GitHub Pages / Vercel / Cloudflare)

由于本项目已配置相对路径构建 (`base: './'`) 并采用 WebRTC P2P 纯静态联机，您可以直接将其部署到任意静态托管服务：

### 1. 部署到 GitHub Pages
```bash
# 1. 安装依赖并构建纯静态资源包
npm install
npm run build

# 2. 将打包好的 dist 目录部署到 gh-pages 分支
npx gh-pages -d dist
```

### 2. 部署到 Cloudflare Pages / Vercel / Netlify
* **Build command**：`npm run build`
* **Build output directory**：`dist`
* 直接关联代码仓库，全球 CDN 自动部署上线！
